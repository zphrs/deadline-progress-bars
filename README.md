A way to mitigate time-blindness with countdowns to deadlines. Each deadline gets a progress bar showing how much time has elapsed between its start and its due date, so you can see at a glance what's getting urgent.

## Usage

- Add and edit deadlines in Notion.
- Choose which deadline to show.
- A deadline is not shown if it's marked as "done" or if its start date hasn't come yet.

## Getting started

Duplicate the Notion template to set up your own tracker, and follow the instructions under the "MacOS topbar setup instructions" dropdown:

[deadline-progress-bars.notion.site](https://deadline-progress-bars.notion.site/)
